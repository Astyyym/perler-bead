# 拼豆图纸生成器

将本地图片识别为 MARD 标准色号，生成逐格标注色号的拼豆图纸、颜色用量统计和 PNG 下载文件。

## 使用

直接用浏览器打开 `index.html`：

```text
index.html
```

不需要安装 Node.js、Python、服务器或其他依赖。

流程：

```text
上传图片 → （按需）调整构图 → 选择长边颗数 → 识别颜色并预览 → 下载 PNG
```

- 上传后默认使用整张图片；裁剪仅用于需要调整构图的场景。
- 只设置成品最长边的颗数，另一边根据图片比例自动计算。
- 识别预览和下载图纸的**每一个色块**都会显示对应的 MARD 色号。
- 下载 PNG 同时包含图纸与“色号—数量”统计。

## 色卡

- **基础版**：A–M 系列，221 色。
- **完整版**：MARD 完整色卡，291 色。

每个成品格先采样图片颜色，再映射为最接近的 MARD 标准色号。

## 项目结构

```text
.
├── index.html          # 唯一页面入口
├── assets/
│   ├── styles.css      # 样式与响应式布局

└── Mard色卡_291色.xlsx # 色卡原始资料
```
